# BindX

BindX 是一个 Windows 桌面工具，用**一个主程序、一个托盘图标、一个配置文件**统一管理两类能力：

- **全局热键**：按一个快捷键显示、隐藏、启动或切换目标应用。
- **键鼠映射**：把某个键盘组合或鼠标按键映射成另一个按键/组合键输出。

`hotkeys` 和 `remap` 目录只是业务模块，不再单独运行、单独维护 GUI 或配置。

## 适用场景

- 给常用应用绑定全局快捷键，比如 `Ctrl+Alt+Q` 控制网易云音乐显示/隐藏。
- 给网页应用绑定快捷键（Gemini、ChatGPT 等浏览器内应用）。
- 给带托盘的应用绑定快捷键（关闭窗口后仍在后台运行的应用）。
- 把鼠标侧键映射成 `Ctrl+W`、`Alt+Tab` 等组合键。
- 希望所有配置集中在一个 JSON 文件里，必要时可手工编辑。

BindX 不做窗口管理器，也不试图完整替代系统快捷键工具。它主要解决一个具体问题：用户只想按一个热键，让不同类型的应用尽量表现出统一的"显示/隐藏"行为。

## 运行环境

- Windows 10 / Windows 11
- Python 3.10+
- 依赖：

```bat
pip install -r requirements.txt
```

`requirements.txt` 包含：`pynput`、`customtkinter`。

## 启动方式

- 双击 `BindX.bat`，或运行 `python app.py`。
- 单实例：通过互斥体 `Global\\BindX` 防止重复启动，第二个实例会提示"BindX 已在运行"并退出。
- 开机启动：在**总览**页的"开机自启动"开关中设置，自动以 `--autostart` 参数隐藏窗口启动。

## 配置

- 配置文件：`data/bindx_config.json`，改动时自动保留 `.bak` 备份。
- **配置属于本机**：该文件已被 `.gitignore` 忽略，不会随 git 提交，各台机器保留各自配置、互不干扰。
- 模板参考：`data/bindx_config.example.json`。
- **跨机同步**：在**总览**页点击"导出配置 / 导入配置"按钮（或托盘菜单"导出配置 / 导入配置"）导出 JSON 文件；在另一台机器导入后会自动热重载全部配置（热键 + 鼠标映射），无需重启。

## 功能说明

### 热键冲突提示

保存热键条目时，如果与其他条目的快捷键完全相同，会弹窗提示存在冲突，但**不会阻止保存**——如何处理（保留哪条、修改哪条）由用户自行决定。

### 组合键注入修复（Ctrl+C 问题）

早期版本在注入按键时会连带释放修饰键，导致物理按住的 `Ctrl+C` 退化成纯 `C`。现在输出统一使用 Windows `SendInput`，并带 BindX 专属注入标记；修饰键匹配只依据物理键盘事件，注入事件不会污染 Ctrl/Alt/Shift 状态。

### 按键检查器

热键页工具栏的"按键检查"按钮可打开按键检查器窗口，实时显示所有键盘/鼠标事件。由 BindX 注入的事件会带 `[BindX 注入]` 标注，方便排查"某个键到底是哪个软件发出来的"。"复制诊断"会把最近 500 条键盘事件日志复制到剪贴板。

### 小键盘数字键

按键录制（添加/编辑条目时）支持小键盘数字键：按下 `NumPad 1`~`NumPad 9` 会记录为 `1`~`9`，可按普通数字键参与匹配。

## 常见问题

- **改了 Python 代码不生效？** 需要退出并重新启动 BindX（导入配置是热重载，代码不是）。
- **热键突然全部失效？** 托盘菜单 → "重新安装 Hook"。
- **想清空配置重新来？** 手动删除 `data/bindx_config.json`（会先备份）。
- **为什么 git 看不到配置变化？** 配置是刻意不提交的，各机器独立保留；需要时用导出/导入功能同步。
