# BindX

BindX 是一款面向 Windows 的**快捷键呼出与键鼠输入增强**工具：给任意桌面应用、浏览器网页应用绑定一个全局热键，一键呼出/收起；把鼠标侧键重映射为任意组合键；配置经 WebDAV 在多设备间同步。

Rust 原生后端 + Tauri v2 + Fluent 风格 WebUI。安装版或便携版任选，无第三方环境依赖，内存占用约 20MB。

---

## 它能帮你做什么

- **一键呼出桌面应用**：网易云音乐、Zotero、Termius、VS Code……热键按下即呼出，再按即收起；没在运行就自动启动。
- **一键呼出网页应用**：通义千问、ChatGPT、Gemini 等浏览器标签页精确匹配切换；标签被关了按热键自动重开（可选"独立应用窗口"形态，体验接近原生应用）。
- **鼠标侧键重映射**：X1/X2 侧键映射为 `Ctrl+W`、`Alt+Tab` 等任意组合；键盘组合映射为输出序列。
- **多设备同步**：坚果云、Nextcloud、Alist、群晖等任意标准 WebDAV；云端拉取后规则秒级热生效，无需重启。
- **无感自更新**：应用内检查新版本并一键更新；安装版静默覆盖、便携版原地替换，配置与快捷方式全程不动。

## 下载与安装

从 [Releases](../../releases) 获取，三选一：

| 产物 | 适合 |
|------|------|
| `bindx-setup.exe` | **推荐**。双击安装，用户级权限（无 UAC 弹窗），装到 `%LOCALAPPDATA%\Programs\BindX`，带开始菜单/卸载项/可选开机自启 |
| `bindx-windows-x64-portable.zip` | 解压即用，配置存在解压目录 `data/` 内，适合 U 盘/多机携带 |
| `bindx.exe` | 单文件本体，与压缩包等价 |

系统要求：Windows 10/11（内置 WebView2 运行时）。

## 快速上手

### 启动与托盘

双击 exe（或开始菜单项）启动，主窗口自动呼出，右下角托盘常驻。托盘菜单：显示主窗口 / 检查更新 / 退出。关闭窗口只是隐藏到托盘，不会退出。

### 呼出 BindX 自身

默认全局热键 `Ctrl + Alt + V`，随时呼出/隐藏主面板。

### 添加一个应用快捷键

1. 快捷键页 → 新增 → 录制或手输热键（如 `Ctrl+Alt+A`）。
2. 目标类型选"桌面客户端"，填进程名（如 `cloudmusic.exe`）或用浏览按钮选 exe；留空则自动识别。
3. 保存。此后该热键全局生效：呼出/收起/未运行自启。

### 添加一个网页应用快捷键

1. 同上录制热键，目标类型选"网页应用"。
2. 填**标题关键字**（如"千问"，用于在浏览器窗口中匹配该标签）；建议再填**目标网址**（标签被关时按它重开）。
3. 可选"打开形态"：独立应用窗口（推荐）或浏览器标签页。页面上的"已安装应用检测"行会实时告诉你该网页是否已被浏览器安装为应用（安装后以完整应用身份唤起）。

### 添加鼠标侧键映射

映射页 → 新增 → 点"录制"后直接按下侧键（或组合键）→ 填输出序列（如 `Ctrl+W`）→ 保存。

### 云同步与更新

- 云同步页：填 WebDAV 地址与账号 → 连接测试 → 上传/下载配置。
- 版本更新页：检查更新 → 查看更新日志 → 一键更新。

## 操作约定

- 编辑弹窗内按 `ESC` 关闭（录制状态除外，此时 ESC 被录为按键）。
- 校验警告以 toast 弹出，在填写页内直接可见。
- 版本号在标题栏/概览/更新页统一显示，与发布版本一致。

## 配置存在哪

- **安装模式**：`%APPDATA%\BindX\bindx_config.json`
- **便携模式**：exe 旁 `data/bindx_config.json`

配置跟着用户走、不跟着程序走：更新、重装均不影响；两台机器一份配置经 WebDAV 同步。

## 常见问题

- **热键没反应？** 概览页确认引擎为"运行中"；确认热键未被其他程序占用。
- **网页应用按热键开了个空白浏览器？** 旧版本行为；v3.0.0 起不会——请为该条目填标题关键字（与网址）。
- **换电脑后网页应用检测不到？** 检测是每台机器各自进行的本地行为；在新机器上把该网页应用窗口打开一次即被学会。
- **安装版和便携版能共存吗？** 能，配置各自独立。

## 开发与构建

- 依赖：Node.js ≥ 18、Rust ≥ 1.80；`npm install` → `npx tauri dev`。
- 发布构建：`npx tauri build --no-bundle`；推送 `v*` tag 触发 CI 产出三产物。
- 仓库路径含空格时 GNU 工具链会失败：用 `CARGO_TARGET_DIR=<无空格路径>` 或在 vcvars 终端用 MSVC（CI 即 MSVC）。

各子系统的**实际行为与实现逻辑**（触发流程、引擎生命周期、检测机制、更新链路、局部流程）见 [`docs/handbook.md`](docs/handbook.md)。
